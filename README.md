⭐ **DESCRIPTION :** Site web ludique de data visualisation sur le thème du voyage et du tourisme international

⭐ **CONTEXTE :** Ce site web a été développé lors de ma deuxième année de BUT MMI dans le cadre d’un cours de Javascript.

⭐ **OBJECTIF :** L’objectif de ce projet était de réaliser un site web de data visualisation, qui affiche les données d’une API de notre choix, sous la forme de notre choix. Nous avons décidé de réaliser un site ludique pour captiver l’attention de notre utilisateur.

⭐ **CE QUE J'AI DÉVELOPPÉ :**
- appel à une API pour récupérer les données
- interprétation et utilisation de ces données pour créer des graphiques et des animations
- page TOP 3 VISITED CITIES OVER THE YEAR avec sliders interactifs et podiums adaptatifs
- page REASON TO TRAVEL avec affichage original sous forme de petits personnages

⭐ **DÉFI TECHNIQUE :** Le podium des villes les plus visitées devait afficher des données différentes selon l'année sélectionnée (2009 à 2019), ce qui demandait de structurer les données sources et de gérer proprement les transitions visuelles entre les jeux de données sans que l'interface ne se recharge brutalement.
